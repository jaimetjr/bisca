# Release notes — 1.3.0 (versionCode 15) · first production release

Play Console takes every language in one paste, wrapped in `<locale>` tags. Copy everything
between the two PASTE markers into Play Console → Production → Create new release →
Release notes.

Only five languages are configured on the release: pt-BR, en-US, es-ES, it-IT, pt-PT. Those are
the five below, in the order Play Console lists them. The rest are parked at the bottom of this
file — paste one in only after adding that language to the store listing, or Play rejects the tag.

Limit is 500 characters per language, counted on the text inside the tags. Longest block is 311.

This is a debut, not a changelog — nobody reading has seen a previous version, so the notes read
as a launch. Later releases go back to listing what actually changed.

Deck wording: it-IT says "40 carte", not "mazzo spagnolo". Briscola is played with regional
Italian decks, so "Spanish" reads as wrong to Italian players. en, es and both pt keep
"Spanish deck" — there it is correct.
